# 🌐 Meu Portfólio Pessoal

Este é o meu portfólio pessoal desenvolvido para apresentar um pouco sobre mim, meus projetos e facilitar o contato profissional. O projeto foi construído utilizando estruturação limpa e estilização própria.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação das páginas web.
* **CSS3**: Estilização e design visual.

## 📁 Estrutura do Projeto

O projeto é composto por 3 páginas principais e uma folha de estilos:

* **`index.html`**: Página principal (Home) com uma introdução sobre mim.
* **`projetos.html`**: Página de portfólio exibindo os trabalhos que desenvolvi.
* **`contatos.html`**: Página com links para minhas redes sociais e canal de e-mail direto.
* **`index.css`**: Arquivo responsável por toda a estilização e layout das páginas.

## 🚀 Como acessar

Você pode visualizar o projeto funcionando diretamente pelo link do GitHub Pages (caso ative no repositório) ou clonando este repositório em sua máquina e abrindo o arquivo `index.html` no seu navegador.
